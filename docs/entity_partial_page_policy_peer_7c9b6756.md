Two concrete implementation traps: attaching an already linked page can create a self-loop/broken neighbors; unconditionally reattaching after taking its last slot admits a full page, so the next request can index `components[capacity]`. The existing four-slot stage policy's fifth allocation is a minimal control. Never promote a later same-class page: that breaks the address/allocation-order argument.
No inspected reader requires global interclass order. Allocation reads `first/next`; world/accounting gates test emptiness; IDE package profiling sums available pages only, so it is not a whole-owner census. Physical/fault/frontend/backend observers walk `owned_next` or deduplicate live component pages; locality's saved owned-head check must remain unchanged. Queries iterate entity tables/columns, not this available index.
`entity_stage_open_result:54` allocates its descriptor in `store.buffers`; stage-local entities/name buffers use `stage.buffers` and staged components use `stage.storage`. These pools are exclusive to their owner. Promotion also writes neighboring page headers: a payload lease or lifetime pin does **not** authorize another worker to mutate the same pool or concurrently inspect its links.
`sem_lower_frontier` prepares stages/capture ranges/leases before its input view and dispatch. Dispatch joins before `sem_stage_wave` / `compiler_kernel_stages_result` hold references, close the view and publish; failures cancel borrowed results before discarding stages. Keep this ordering and first-cause restoration. Publication transfers both private pools; discard releases private owners and asserts both owned chains empty before destroying the stage.
Do not infer a universal `views==0` allocator precondition: coordinator view/query-plan creation itself can use `store.buffers` with pins present. Published component mutation is Busy while pinned; private leased mutation remains isolated. Reuse only existing exclusive allocation sites, with no new worker access to store pools and no concurrent physical observer. This review does not prove general race freedom.
