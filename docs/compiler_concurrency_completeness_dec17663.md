Actual typed kernel dispatch is [work_kernel_execute](../scaffolding/compiler/compiler_kernels.tower). The common execution path is [compiler_kernel_dispatch_admitted_result](../scaffolding/compiler/compiler_kernel.tower) → [work_pool_batch_result](../scaffolding/library/work_pool.tower): caller plus admitted extra lanes claim successive jobs from one bounded batch, rather than one fixed job per worker. Zero extras execute inline; partial submission drains before return. WorkGraph is the derived readiness/access index; it does not own or duplicate semantic payloads. [sem_scratch_private](../scaffolding/compiler/semantic_support.tower) resets mutable scratch in each worker; body continuation transfer retains that ownership explicitly.
[frontend_units_open](../scaffolding/compiler/frontend_units.tower) binds all unit worlds to one synchronized WorkBudget. Each outer job reserves one lane; [ParserAdmission](../scaffolding/compiler/parser_workers.tower) and [sem_workers_admit_result](../scaffolding/compiler/semantic_context.tower) reserve only available extras with minimum zero. [work_budget_reserve/release_result](../scaffolding/library/work_budget.tower) validates owner/revision/generation, bounds charged bytes and wakes an outer coordinator when capacity returns. Pool slots are not entitlement; [compiler_worker_capacity](../scaffolding/compiler/worker_policy.tower) also clamps to host transport capacity. Nonthreaded/zero-extra execution stays inline; native overlap does not prove nested browser parallelism. Grants outlive joins/publication; raw analysis buffers, foreign LLVM heaps and ledger backing remain outside the charged-byte census, so this is not a process-RSS cap.
[sem_bodies](../scaffolding/compiler/semantic_body_work.tower), [sem_query_pipeline_pump](../scaffolding/compiler/semantic_query_pipeline.tower) and [sem_lifecycle_queries_pump](../scaffolding/compiler/semantic_lifecycle.tower) alternate Progress/Waiting/Complete/Failed producers. work_suspend/access adds the newly discovered edge after the worker relinquishes claims; work_observe records completed reads. [work_ticket_valid/reset/cancel](../scaffolding/library/work_graph.tower) rejects stale revision/profile/dispatch receipts. The owning quiescent pipeline, not an individual Waiting worker, selects source-ordered dependency/cycle diagnostics.
Cancellation is logical invalidation plus physical drain: frontend_units_cancel cancels CompilerWork, joins every admitted unit, settles backend continuations, releases grants and closes the view; frontend_units_close destroys worlds then requires work_budget_dispose success. A WorkGraph cancel alone does not stop/free a worker. Semantic finite waves join before [sem_stage_wave](../scaffolding/compiler/semantic_context.tower) holds queued references, closes the last view, publishes/discards stages and only then releases lane reservations. No asynchronous mid-compilation edit guarantee follows from this contract.

**Lowering serialization, exact scope:** the [accepted attribution](compiler_lowering_coordinator_e3958206.md) measured 4105 jobs in 17 lowering batches (16×256+9); 312 counts all semantic dispatch waves. Its 30864 ready-census observations are cumulative revisits, not distinct runnable leases. Selection revisits 38921 finished entries; this is verified redundant traversal, not proof of starvation or a missing dependency producer.
[sem_capture_ranges](../scaffolding/compiler/semantic_capture_work.tower) walks checked executable edges once per expression-lowering admission, attaches capture components to source initializers, records the exact lowering ticket and leases each declaration. The function lease is not recursive. [entity_stage_lease_result](../scaffolding/library/entity_stage.tower) mutates lease/storage ownership and explicitly returns Busy while any store view exists; component creation likewise cannot be moved into a shared read-only view. Workers later record initializer ranges only into those pre-admitted payloads.
Thus stage creation/component admission/lease reservation and publication are necessarily coordinator-owned **under this implementation's contracts**. The whole discovery walk is not proven inherently serial: separating frozen discovery from structural reservation could change granularity, but no such independent producer/profitable split is established here. The grouped 114/198ms serial/four observation does not attribute that split, and cannot be subtracted from kernel CPU as idle wall. Removing the 256 ownership window or publishing while peers retain pins is not a valid shortcut.
The current batch-wide join also withholds graph-ready work outside its window until leases release; within each window workers refill. Arbitrary intra-function parsing/lowering subtrees, cross-phase structural overlap and per-result early stage publication are **not** implemented guarantees. These bounded scheduling choices limit utilization; no required language behavior is shown missing because of them. Do not call all serialization a semantic necessity or call those future granularities an absent concurrency framework.
